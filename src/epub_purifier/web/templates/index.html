    Scanned and cleaned

    Project Gutenberg, Wikisource, Internet Archive, Open Library, Standard Ebooks, OAPEN and DOAB editions are public domain or openly licensed: the EPUB is fetched to this server, scanned and cleaned before you download it, and the temporary copy is deleted five hours after the download starts. Items marked “available elsewhere” only open the source's own page and are never downloaded here. If you already have such a file and the right to modify it, clean it with step 2 below: the same scanning and cleaning applies. Sources this server added appear beside the built-in ones.

    Temporary cleaned downloads

    Fetched books are scanned, cleaned and held in private temporary storage for five hours after the server starts downloading them — downloaded or not. A cleanup pass runs every ten minutes, and expired copies are removed even after a restart.

              Bookkeeping

              Not a malware scanner. EPUB Purifier inspects archive structure and markup only. It never executes scripts, and a clean report is not a guarantee that a file is safe.

              Only clean files you own or are authorised to modify. EPUB Purifier does not remove DRM or bypass access controls, and it links to sources it cannot download from.
